# ShoeCart

A simple front-end shoe shopping website built with HTML, CSS, and JavaScript. It includes a login screen, product catalog, shopping cart, and order placement form.

## Demo

This project is a small e-commerce UI for a shoe store where users can:
- log in
- browse products
- add items to the cart
- remove items from the cart
- enter customer details
- place an order

## Features

- Login page with username/password validation
- Men and women shoe product sections
- Add-to-cart functionality
- Cart item removal
- Live total price updates
- Checkout form with validation
- Order confirmation message
- Responsive styling for a modern storefront look

## Tech Stack

- HTML5
- CSS3
- JavaScript

## How to Run

You can run this project in two simple ways:

### Option 1: Open directly in browser
- Open `index.html` in your browser

### Option 2: Run a local web server
```bash
python -m http.server 8000
```

Then open:
```text
http://localhost:8000
```
